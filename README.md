# FXXXXXN AMR CONTROL UI Prototype

无需安装任何依赖。

## 使用方式

直接双击 `index.html` 即可运行，也可以使用任意静态文件服务器访问项目根目录。

## 技术构成

- HTML5
- CSS Variables
- Vanilla JavaScript
- SVG 工厂地图和数据图形

## 页面结构

- 顶部栏：9 个一级模块
- 左侧栏：当前模块下的二级页面
- `pages/`：27 个独立 HTML 页面
- `assets/`：共享设计系统与演示交互

所有车辆、任务、机台、日志和 API 响应均为前端演示数据。

## 协作文档

- `系统架构.md`：模块边界、核心对象、业务链及协作约定。
- `前端UI需求文档.md`：页面功能、字段、状态、交互和验收标准。
- `AMR系统设计文档.md`：产品背景、早期方案和扩展能力参考。
